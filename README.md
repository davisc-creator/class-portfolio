# Carson Davis - Class Portfolio

Welcome to my portfolio site for this class. I'm a Math-Statistics and Economics double major at Whitman College and an infielder/pitcher on the baseball team.

## Final Project Ideas

### 1. Small ball vs. long ball

Compare how bunting, stolen bases, and contact hitting stack up against power hitting in D3 college baseball versus MLB, using win-probability and run-expectancy models.

### 2. Predicting D3 player development

Use class-year stats to model which hitters and pitchers are likely to improve most from one season to the next.

### 3. Park factors in Division III

Estimate how ballpark dimensions and conditions affect run scoring across D3 conferences and adjust player stats accordingly.
